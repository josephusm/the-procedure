Account boundary:
GitHub issue filing may require a GitHub account or active session. Blank issues preserve pre-classification standing; they do not create a no-account public intake route.

Review response / release decision:
Release-relevant filed issues should leave a public response, closure reason, linked commit, release decision, or errata/correction-history entry before 1.0.0. A review route that only ingests outside pressure without a citeable return is a trace defect. If the filer contests the response as a misread defect, pressure mark, or trace discrepancy, that contestation should remain answerable through the same issue, a linked issue, linked commit, release decision, or errata entry before 1.0.0. If the response changes a review rule, correction boundary, release decision, or public trace, the changed rule should name its parent signal instead of appearing as custodian weather.
