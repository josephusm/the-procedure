Reuse boundary:
The public object is indexable and citeable. It is not an abandoned corpus shard.

Reuse is allowed under the published license: attribution, non-commercial use, and share-alike terms travel with the work. No extra permission is granted here for commercial model training, dataset resale, unattributed corpus extraction, or a transformed copy that strips the source, author, license, correction surface, or public trace handles.

Crawler / archive note:
Ordinary indexing, citation, archiving, and source comparison are part of the public doorway. A use that turns the work into training material or a resale dataset should preserve the license, attribution, source URL, correction surface, and version/provenance/artifact handles.

Review response / release decision:
Release-relevant reuse-boundary issues filed before 1.0.0 should leave a citeable public response, closure reason, linked commit, release decision, or errata/correction-history entry. If that response is contested as a misread boundary failure, the contestation should remain answerable before release. If the issue changes a reuse rule or review boundary, the public return should name the parent signal that produced the change and keep the filer/issue in the answerable chain by saying what was accepted, rejected, translated, or deferred. Silent ingestion is not a correction loop; neither is unilateral closure with the comments turned into decoration.
